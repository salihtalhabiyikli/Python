## JWT — Token Doğrulama

---
[[SQL ALCHEMY]]
[[FAST API]]
### Ne Yapmak İstiyoruz?

Kullanıcı token gönderdi, biz:

```
1. Token geçerli mi?
2. Süresi dolmamış mı?
3. İçinde kim var?
```

sorularını cevaplıyoruz.

---

### Doğrulama Fonksiyonu

python

```python
from jose import jwt, JWTError

def token_dogrula(token: str):
    try:
        veri = jwt.decode(
            token,
            SECRET_KEY,
            algorithms=[ALGORITHM]
        )
        return veri

    except JWTError:
        return None
```

---

### jwt.decode() Ne Yapıyor?

3 şeyi kontrol ediyor:

```
1. İmza geçerli mi?
   → SECRET_KEY ile kontrol et

2. Süresi dolmamış mı?
   → exp alanına bak

3. Her şey tamam → veriyi döndür
```

---

### Sonuç Ne Dönüyor?


```python
veri = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])

print(veri)
# → {"sub": "ahmet@mail.com", "exp": 123456}
```

---

### Hatalı Token Gelirse

python

```python
try:
    veri = jwt.decode(...)   # hata fırlatır

except JWTError:
    return None              # None döner
```

`JWTError` şu durumlarda fırlatılır:

```
Token değiştirilmişse    → imza bozuk
Süresi dolmuşsa          → exp geçmiş
Geçersiz token gelirse   → format yanlış
```

---

### Kullanımı

python

```python
token = "eyJhbGci..."

veri = token_dogrula(token)

if veri is None:
    # geçersiz token
    raise HTTPException(status_code=401, detail="Geçersiz token")

email = veri["sub"]   # "ahmet@mail.com"
```

