### Token Neden Var 
- Kullandığımız internet protollerinin hafızası yoktur. Siz her girişinizde ilk defa giriş yapmışsınız gibi algılar. 
- Eğer token olmasaydı sizin her sosyal medya faaliyetinden tekrar tekrar hesap girişi yapmanız gerekirdi.

### Token Sistemi Nasıl Çalışır?
- **Giriş (Login):** Kullanıcı adı ve şifreni sunucuya gönderirsin.
    
- **Onay ve Bilet Üretimi:** Sunucu şifreni doğrular (Passlib ile). Eğer doğruysa, sana özel, kimsenin taklit edemeyeceği, şifreli ve uzun bir metin üretir. İşte bu metin **Token**'dır.
    
- **Response Etmek:** Sunucu bu token'ı senin tarayıcana veya mobil uygulamana geri gönderir (`response` eder).
    
- **Cepte Saklama:** Tarayıcın (veya telefonun) bu token'ı hafızasında saklar.
    
- **İçeride Gezinme:** Sen uygulamada ne yaparsan yap (Yorum yaz, fotoğraf beğen, sayfayı yenile), tarayıcın arka planda her isteğin yanına o token'ı da ekler.
    
- **Hızlı Kontrol:** Sunucu şifreye bakmaz. Gelen token'a bakar, "Tamam, bu token geçerli ve Ahmet'e ait" der ve işlemi yapar.

### Token Oluşturma Fonksiyonu

```python
def token_olustur(veri: dict) -> str:
    kopyala = veri.copy() # Orjinal veri bozulmasın diye

    # Token ne zaman expire olacak?
    bitis = datetime.utcnow() + timedelta(minutes=TOKEN_SURESI) # Bu zamandan 30 dk sonrasına
    kopyala.update({"exp": bitis})

    # Token'ı oluştur
    token = jwt.encode(kopyala, SECRET_KEY, algorithm=ALGORITHM)
    return token
```
