### İlişki Türleri

```
One to One    → bir kullanıcının bir profili
One to Many   → bir yazarın çok makalesi   ← en yaygın
Many to Many  → bir ürünün çok kategorisi
```
[[SQL ALCHEMY]]
[[FAST API]]
### Bire Çok 
```python
# 1. Çocuk tabloda ForeignKey
class Makale(Base):
    __tablename__ = "makaleler"

    id       = Column(Integer, primary_key=True)
    baslik   = Column(String)
    yazar_id = Column(Integer, ForeignKey("yazarlar.id"))  # ← burası

# 2. Ana tabloda relationship
class Yazar(Base):
    __tablename__ = "yazarlar"

    id       = Column(Integer, primary_key=True)
    ad       = Column(String)
    makaleler = relationship("Makale", back_populates="yazar")  # ← burası
```

Yazarlar tablosu          Makaleler tablosu
┌────┬───────┐            ┌────┬─────────┬──────────┐
│ id │  ad   │            │ id │ baslik  │ yazar_id │
├────┼───────┤            ├────┼─────────┼──────────┤
│ 1  │ Ahmet │←───────────│ 1  │ Makale1 │    1     │
│ 2  │ Ayşe  │←───────────│ 2  │ Makale2 │    2     │

                      │   └────┴─────────┴──────────┘
                      │
              "yazar_id=1 → Ahmet'in makalesi"

### relationship() Nedir?
- Normalde bir kullanıcının verileri çekmek için sqlde JOIN kullanırız. relationship kullandığınızda her tablo bir metod gibi olur ve daha hızlı gezinebilirsiniz. 
-  **SQLMantığı:** `SELECT * FROM makaleler WHERE yazar_id = 1;`
    
- **SQLAlchemy Mantığı:** `kullanici.makaleler` (Sana o kullanıcının tüm makalelerini bir liste olarak döner).
```python
import sqlalchemy.orm import relationship

class Yazar(Base):
__tablename__="yazarlar"

id= Column(Integer, primary_key=True)
ad = Column(String)
makaleler= relationship("Makale",back_populates="yazar")


class makale(Base):
	__tablename__="makaleler"
	
	
	id= Column(Integer,primary_key=True)
	baslik=Column(string)
	yazar_id= Column(Integer,ForeignKey("yazarlar.id"))
	yazar= relationship("Yazar",back_populates="makaleler")
```
```
# Direk erişebiliyoruz:
yazar.makaleler    # yazarın tüm makaleleri
makale.yazar       # makalenin yazarı
```

### Kullanım Örnekleri

```python
# Yazarı ve makalelerini getir
yazar = db.query(Yazar).filter(Yazar.id == 1).first()
print(yazar.ad)          # "Ahmet"
print(yazar.makaleler)   # [Makale1, Makale3]

# Makaleyi ve yazarını getir
makale = db.query(Makale).filter(Makale.id == 1).first()
print(makale.baslik)     # "Makale1"
print(makale.yazar.ad)   # "Ahmet"
```
