### DataBase.py 
``` python
from sqlalchemy import create engine
from sqlalchemy.ext.declarative import declarative_base 
from sqlalchemy.orm import sessionmaker
```

"Create engine" : Veritabanına bağlantı motoru oluşturur.
"declarite base" : Bu kısım bizim modelimizin miras  alacağı kısımdır. Bunu hazır bir şablon gibi düşünebiliriz.
sessionmaker : Veritabanı işlemleri için **oturum fabrikası** oluşturur. Her istek kendi oturumunu açar, işlemini yapar, kapatır.

### VeriTabanı URL 
```
# SQLite — geliştirme ortamı için
VERITABANI_URL = "sqlite:///./uygulama.db"
#                  ↑       ↑  ↑
#               tip    konum  dosya adı
```

```python
engine=create_engine(
VERITABANI_URL,
connect_args= {"check_same_thread":False}
)
```

SQLite varsayılan olarak **tek thread** ile çalışır. FastAPI birden fazla isteği aynı anda işleyebilir . Bu satır olmadan hata alırsınız.

``` python 
SessionLocal= sessionmaker(
autocommit = False,
autoflush= False,
bind= engine
)
```

burada 
#### `autocommit=False` neden?

Her işlemden sonra otomatik kaydetmesin. Sen **manuel** `db.commit()` diyeceksin. Böylece hata olursa geri alabilirsin.

#### `autoflush=False` neden?

Sorgu yapmadan önce otomatik flush yapmasın. Daha fazla kontrol sende olsun.

#### `bind=engine` neden?

Bu session'ın hangi veritabanıyla konuşacağını belirtir.

### Base



```python
Base = declarative_base()
```

Tüm tablo modelleri bunu miras alır:

python

```python
# models.py
class Urun(Base):       # Base'den miras aldı
    __tablename__ = "urunler"
    ...

class Kullanici(Base):  # Base'den miras aldı
    __tablename__ = "kullanicilar"
    ...
```

Base sayesinde SQLAlchemy hangi sınıfların tablo olduğunu bilir.

Bu bir database dosyasının genel yapısı ve motor özelliklleridir 

```python
from sqlalchemy import create_engine
from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy.orm import sessionmaker

VERITABANI_URL = "sqlite:///./uygulama.db"

engine = create_engine(
    VERITABANI_URL,
    connect_args={"check_same_thread": False}
)

SessionLocal = sessionmaker(
    autocommit=False,
    autoflush=False,
    bind=engine
)

Base = declarative_base()

def db_al():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```
