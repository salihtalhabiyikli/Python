- Bir modelin kriterleri Nelerdir?
``` python
class Kullanici(Base): # Baseden Miras almak
    __tablename__ = "kullanicilar" # Veritabanındaki tablo adı
    id = Column(Integer, primary_key=True)  # En az bir primary key 
```

Gerisi ihtiyaca göre belirlenir. 


### Sütun Parametreleri
- Sütun veri tiplerini belirleyip nasıl davranacaklarını söyleriz 
```python
id = Column(Integer, primary_key=True)
#            ↑            ↑
#           tip        parametre
```
### primary_key
```python
id = Column(Integer, primary_key=True)
```

- Her satırın **benzersiz kimliği**
- Otomatik artar (1, 2, 3...)
- Her tabloda **zorunlu** olmalı
- Aynı id iki satırda **olamaz**
### nullable

```python
ad    = Column(String, nullable=False)   # boş olamaz
notlar = Column(String, nullable=True)   # boş olabilir (varsayılan)
```

```
nullable=False → bu alan zorunlu, boş geçilemez
nullable=True  → bu alan opsiyonel, boş geçilebilir
```
### unique

```python
email = Column(String, unique=True)
```

- Aynı değer iki kez **girilemez**
- Email, kullanıcı adı gibi alanlar için kullanılır
### default
```python
tamamlandi = Column(Boolean, default=False)
stok       = Column(Integer, default=0)
```

- Değer girilmezse **varsayılan değeri** kullanır
- Sen vermesen bile veritabanı otomatik koyar

### onupdate

```python
from datetime import datetime

guncellendi = Column(DateTime, onupdate=datetime.utcnow)
```

- Satır **güncellendiğinde** otomatik çalışır
- "Bu kayıt en son ne zaman güncellendi?" için kullanılır

#### Genel Proje Örneği 
```python 
from sqlalchemy import Column, Integer, String, Boolean, DateTime, ForeignKey
from datetime import datetime
from database import Base

class Kullanici(Base):
    __tablename__ = "kullanicilar"

    id          = Column(Integer, primary_key=True, index=True)
    ad          = Column(String, nullable=False)
    email       = Column(String, unique=True, nullable=False, index=True)
    sifre       = Column(String, nullable=False)
    olusturuldu = Column(DateTime, default=datetime.utcnow)

class Todo(Base):
    __tablename__ = "todolar"

    id           = Column(Integer, primary_key=True, index=True)
    baslik       = Column(String, nullable=False)
    tamamlandi   = Column(Boolean, default=False)
    olusturuldu  = Column(DateTime, default=datetime.utcnow)
    guncellendi  = Column(DateTime, onupdate=datetime.utcnow)
    kullanici_id = Column(Integer, ForeignKey("kullanicilar.id"))****
```
