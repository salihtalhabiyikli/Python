##### Base Model Tasarımı 

```python 
from pydantic import BaseModel, Field

class User(BaseModel):
    id: int                                  # zorunlu
    name: str                                # zorunlu
    email: str | None = None                 # opsiyonel, varsayılan None
    role: Literal["admin", "user"] = "user"  # varsayılanlı
    tags: list[str] = []                     # güvenli, Pydantic her örnek için kopyalar
    age: int = Field(default=18, ge=0, le=150, description="Yaş")

u = User(id=1, name="Ali")
print(u)        # id=1 name='Ali' email=None role='user' tags=[] age=18
print(u.name)   # Ali

```


#### Tip Tasarımı 

```python 
class Item(BaseModel):
    qty: int
    price: float
    active: bool

i = Item(qty="5", price="9.99", active="true")
print(i)  # qty=5 price=9.99 active=True
```
