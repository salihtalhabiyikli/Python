2000 yılında bilgisayar bilimci Dr. Roy Fielding tarafından doktora tezinde tanımlanmıştır. REST yani Repsentational State Transfer olarak adlandırılan teknoloji aslında bir api mimarisidir. 

Temel mantıkta her şey bir kaynak etrafında döner. Kaynak veritabanındaki veri olabilir. Her kaynağın bir URLsi vardır ve bu kaynak üzerinde ne yapmak istediğinizi http metodu ile belirtirsiniz.
