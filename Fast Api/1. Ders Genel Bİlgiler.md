#### HTTP METODLARI 
- FastAPI endpointlerinde doğrudan http metodlarını kullanır. 
### 1. GET — Veri Okuma

Sunucudan veri **almak** için kullanılır. Genelde body içermez, parametreler URL üzerinden gönderilir.

python

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/urunler")
def urunleri_listele():
    return {"urunler": ["kalem", "defter", "silgi"]}

@app.get("/urunler/{urun_id}")
def urun_getir(urun_id: int):
    return {"urun_id": urun_id, "isim": "kalem"}
```

### 2. POST — Yeni Veri Oluşturma

Sunucuya yeni bir kaynak **eklemek** için kullanılır. Genelde bir request body (Pydantic modeli) ile veri gönderilir.

```python
from pydantic import BaseModel

class Urun(BaseModel):
    isim: str
    fiyat: float

@app.post("/urunler")
def urun_ekle(urun: Urun):
    return {"mesaj": "Ürün eklendi", "urun": urun}
```

### 3. PUT — Veriyi Tamamen Güncelleme

Var olan bir kaynağın **tamamını** güncellemek için kullanılır. Genelde tüm alanların gönderilmesi beklenir.

python

```python
@app.put("/urunler/{urun_id}")
def urun_guncelle(urun_id: int, urun: Urun):
    return {"mesaj": f"{urun_id} numaralı ürün güncellendi", "yeni_veri": urun}
```

### 4. PATCH — Veriyi Kısmen Güncelleme

Bir kaynağın **sadece belirli alanlarını** güncellemek için kullanılır. Bu yüzden model alanları genelde `Optional` yapılır.

python

```python
from typing import Optional

class UrunGuncelle(BaseModel):
    isim: Optional[str] = None
    fiyat: Optional[float] = None

@app.patch("/urunler/{urun_id}")
def urun_kismi_guncelle(urun_id: int, urun: UrunGuncelle):
    return {"mesaj": f"{urun_id} kısmen güncellendi", "degisenler": urun.dict(exclude_unset=True)}
```

### 5. DELETE — Veri Silme

Bir kaynağı **silmek** için kullanılır.

python

```python
@app.delete("/urunler/{urun_id}")
def urun_sil(urun_id: int):
    return {"mesaj": f"{urun_id} numaralı ürün silindi"}
```

### Ek Metodlar (daha az kullanılan)

- **HEAD** — GET ile aynı ama sadece header döner, body dönmez (varlık kontrolü için).
- **OPTIONS** — Bir endpoint'in hangi metodları desteklediğini öğrenmek için (CORS'ta otomatik kullanılır).

python

```python
@app.head("/urunler/{urun_id}")
def urun_var_mi(urun_id: int):
    return

@app.options("/urunler")
def desteklenen_metodlar():
    return {"metodlar": ["GET", "POST", "PUT", "DELETE"]}
```
