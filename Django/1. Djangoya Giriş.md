#### Template 
Geleneksel veri odaklı bir web sitesinde bir web uygulaması web tarayıcısından gelen Http isteklerini bekler.  Bir istek alındığında, uygulama URL'ye ve muhtemelen verideki bilgilere dayanarak neyin gerekli olduğunu belirler `POST`. `GET`Gereksinime bağlı olarak, bir veritabanından bilgi okuyabilir veya yazabilir ya da isteği karşılamak için gereken diğer görevleri gerçekleştirebilir.Uygulama daha sonra web tarayıcısına bir yanıt döndürür; genellikle alınan verileri bir HTML şablonundaki yer tutuculara ekleyerek tarayıcının görüntülemesi için dinamik olarak bir HTML sayfası oluşturur.

Model : 
1. Verinin kendisidir. Veritabanındaki her tabloyu bir python sınıfı olarak yazarsınız. SQL yazmanıza gerek kalmaz. 

```python 
from django.db import models 

class Yazi (models.Model):
baslik =models.CharField(max_length=300)
icerik= models.TextField()
tarih=models.DateTimeField(auto_now_add=True)

```


View :
1. Asıl işi yapan kısımdır İstei alır gerektiği zaman modelden veri çeker sonra bir templatee verip yanıt döner 

```python 
# views.py
from django.shortcuts import render
from .models import Yazi

def yazi_listesi(request):
    yazilar = Yazi.objects.all()
    return render(request, "yazi_listesi.html", {"yazilar": yazilar})
```


Template 
1. Kullanıcının gördüğü HTMLdir. İçine djangonun şablon dilini yazarak Viewdan gelen veriyi gösterirsiniz. 
```python 
{% for yazi in yazilar %}

<h2>{{ yazi.baslik}} </h2>
<p> {{yazi.icerik}} </p>
{% endfor %}
```

urls.py 
1. Gelen adresin hangi viewe gideceğini belirler 
```python 
from django.urls import path 
from . import views 

urlpatterns = [
path("yazilar/" , views.yazi_listesi),
]
```

### Akış

Tarayıcıya `/yazilar/` yazdığınızda şunlar olur:

1. Tarayıcı isteği gönderir.
2. **urls.py** adresi görür, `yazi_listesi` view'ını seçer.
3. **View**, **Model** aracılığıyla veritabanından yazıları çeker.
4. View, bu verileri **Template**'e gönderir.
5. Template HTML'i üretir, yanıt tarayıcıya döner.
